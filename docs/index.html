Frost that stays readable.

A glassmorphism library with light and dark themes. Blur where the browser can do it, solid color where it cannot, and one button vocabulary shared with the bbuilder studies.

  <button class="frost-btn frost-btn-action">
    Click me
  </button>
</div>

One button vocabulary

Frost Glass grew signature controls as frostdark-button-* and frostlight-button-*. The shared component file, and the private bbuilder repo, use frost-btn-*. Both names are in the stylesheet now. New markup should use the canonical column. Put it inside frost_dark or frost_light.

Role Canonical Legacy dark Legacy light
Base layout frost-btn Included in the legacy button rules
Glass action frost-btn-action frostdark-button-action frostlight-button-action
Raised glass frost-btn-raised frostdark-button-raised frostlight-button-raised
Glass danger frost-btn-action-danger frostdark-button-action-danger frostlight-button-action-danger
Small / icon frost-btn-action-sm · frost-btn-action-icon frostdark-button-action-sm · frostdark-button-action-icon frostlight-button-action-sm · frostlight-button-action-icon
Action row frost-btn-action-group frostdark-button-group frostlight-button-group
Quiet set frost-btn-primary secondary outline ghost Same classes. This is the set bbuilder already documents.
Tinted frost-btn-danger frost-btn-success Not aliases of the glass action buttons.
Parametric glass frost-btn-glass Alias button--glass from the bbuilder studies.
